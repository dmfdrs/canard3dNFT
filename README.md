# Miguel Stream Monitor

Static HTML + CSS edition of the Miguel Stream Monitor dashboard.

This version is designed for simple static hosting such as GitHub Pages. It does not call Twitch or Instagram APIs directly, does not scrape Instagram, and does not claim exact page enter/leave tracking. The enter/leave panels are clearly labeled as estimates/placeholders for a future Twitch-backed implementation.

## Files

- `index.html` - dashboard markup
- `styles.css` - dark neon esports styling
- `public/assets/miguel-duck-logo.png` - Miguel duck logo
- `public/assets/miguel-dashboard-reference.png` - design reference asset

## Run Locally

Open `index.html` in a browser.

No build step is required.
